# Données et confidentialité

## Game.log

`Game.log` est lu localement et en lecture seule pour détecter la localisation.
Le fichier complet n'est jamais copié, archivé ou ajouté au registre
communautaire.

## Bouton Wi-Fi

Aucune donnée de registre n'est écrite sans action du joueur. Lorsqu'il valide
le bouton Wi-Fi, le programme enregistre le lieu saisi et le code de
localisation le plus probable, avec un contexte technique minimal.

## Données exclues

Le registre n'enregistre pas le nom du joueur, son identifiant de compte ou le
chemin complet de `Game.log`.

## Fichier partageable

```text
%LOCALAPPDATA%\PublicRealTimeCheckerData\registry\Public_Real_Time_Checker_Registry.json
```

Le programme n'envoie pas ce fichier automatiquement. Le joueur choisit
lui-même de le transmettre.
