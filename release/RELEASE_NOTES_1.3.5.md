# SC-RTLT Public 1.3.5

SC-RTLT is an unofficial, community-made Star Citizen companion for Windows.

## Highlights

- 14 independent fan-made Star Citizen radio streams.
- One embedded browser for curated Star Citizen-related websites and custom
  user-added sites.
- A movable, always-on-top interface designed for use while playing, without
  injecting code into or modifying Star Citizen.
- Complete English and French interface support.
- A yellow update button at the top of Settings that downloads a verified
  GitHub Release and restarts the widget automatically.
- Local location detection, Verse time, HUD layout, and color customization.

## Install

1. Download `SC-RTLT_Public_1.3.5_Windows.zip`.
2. Extract the archive completely.
3. Run `Setup.bat`.
4. Use `Launcher.vbs` for later launches.

Windows SmartScreen may display a warning because the application is not
signed with a commercial code-signing certificate.
