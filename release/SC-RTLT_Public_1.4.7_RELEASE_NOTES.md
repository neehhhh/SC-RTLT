# SC-RTLT Public 1.4.7

## Changes

- Group UI is marked as Alpha in the public settings.
- Added a master `Enable Group UI (Alpha)` switch.
- Group UI is disabled by default when no previous preference exists.
- The Group UI enable/disable choice is persisted across sessions.
- When Group UI is disabled, its HUD blocks stay hidden and periodic RSI profile refreshes are stopped.
- Windows runtime validation now focuses on critical runtime/build checks instead of historical UI regression checks.
- Validation failures now identify the failing `[VERIFY]` step and include the Python traceback in the installer log.
- Includes the Group/Raid UI party-event reliability fixes from the 1.4.x test builds.
- Includes the expanded vehicle/manufacturer HUD palette census, including Consolidated Outland HoverQuad aliases, Greycat Industrial, Tumbril Land Systems, and ARGO ATLS classification.
